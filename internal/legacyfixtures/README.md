# Frozen legacy regression scenarios

These packages preserve the definitions and assertions formerly generated by
the compiler's nested `go test` round trips. They run directly with the normal
Go test suite; no compiler, code generation or subprocess is involved.

The in-package rules scenarios likewise use frozen typed constructors in
`mtg/rules/legacy_card_fixtures_test.go`. Their exact metadata keys identify
existing fixtures; Oracle text is not interpreted. Each lookup builds a fresh
definition graph, including token definitions.

Write new scenarios using typed card definitions or authored card programs.
Update existing fixtures as ordinary Go when a shared type changes. These are
test-only definitions, not additional production registrations.
